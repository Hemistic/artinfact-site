# Artinfact public website

Official website, feature atlas, support, privacy policy and terms maintained by Hemistic. English is the default at index.html; Chinese starts at index-zh.html. Static HTML/CSS, no tracking scripts or forms.

The feature atlas adapts the existing Artinfact feature board: 20 descriptions across five groups. Its 16 shared original screenshots are 1920 × 1080, light theme, captured from the local 0.13.41 demo in Chinese. These are historical product views, not new release validation or a recorded demo.

Deploy main branch / root with GitHub Pages. Only public website material belongs here; no private PDFs, credentials or plugin runtime. Public plugin review is not yet submitted.

Maintainer confirmed: no additional telemetry; support email deleted within 90 days after case closure except legally required retention.
