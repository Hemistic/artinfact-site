Original PDFs & annotations

Read, highlight and annotate original pages. Optional local MinerU parsing prepares figures, equations and reference material.

Editable research boards

Write Markdown inside cards. Organize ideas with connections and colored regions, or explore relationships in the graph.

AI on request

Start research from a card, connection or region. The host Agent reads relevant sources through MCP and writes back explanations, insights or annotations.

Take your work with you.

Export a board as Markdown with images, an editable .artinfact package, or JSON Canvas .canvas. Interactions vary between compatible applications.

Current installation scope

The public candidate targets Windows x64 desktop hosts with Node.js 22+. MinerU and its models are separate downloads. AI, Pages and translation depend on their respective host or external service. Public directory release is still being prepared; this website is not a claim of approval.
