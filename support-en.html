Support & release information

Artinfact is maintained by Hemistic. For support and privacy requests, contact 414482116@qq.com.

Release status

The tested private installation is version 0.13.42. A public candidate is being prepared from this version. Public directory review has not been submitted and the plugin is not yet publicly listed. The current package targets Windows x64; other platforms require a separate build and validation.

Local MCP submissions require organization approval. A public installation link will be added after review and release. Historical private links and this website are not public installation endpoints.

Reporting an issue

  • Include the plugin version, operating system and affected feature.
  • Describe the steps needed to reproduce the issue.
  • Share only redacted errors or a minimal sample. Remove tokens, passwords, private paths and unrelated content.

Do not upload private PDFs, chats or credentials to public GitHub issues. Discuss necessary material by email. Support messages are used to handle your request and deleted within 90 days after closure, except where retention is legally required. There is no guaranteed response time.

Common questions

Is MinerU required to read a PDF?

No. Original PDF reading is independent of structural parsing. MinerU produces Markdown, structured JSON and source assets.

Does a free plugin mean all connected services are free?

No. Artinfact has no plugin subscription or in-plugin purchases. Host AI, Pages and other services have their own conditions.

Is everything offline?

Local reading and parsing run on your computer. AI, Pages, enabled translation and downloads can involve external processing. See the privacy policy.

Does deleting a card remove every copy?

No. Shared cards, archives, attachments, exports, Pages and host conversations must be managed separately.
