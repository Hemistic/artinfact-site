隐私政策

更新与生效日期：2026-10-24

本政策说明 Hemistic 维护的 Artinfact 插件及本网站如何处理数据。联系邮箱：414482116@qq.com。

1. 本机资料和权限

PDF、笔记、批注、解析产物、白板、图片和导出主要保存在你选择的本机资料目录，默认是系统文档目录下的 Artinfact。设置、阅读状态和诊断可能另存在本机插件数据目录。文档目录若由 OneDrive 等服务同步，会受你的系统配置影响。

本机 MCP 以宿主授予的权限工作。请只授权处理你有权使用的文件。基础卡片准备从解析产物提取资料，不自动生成 AI 观点。

2. 哪些操作涉及外部服务

功能相关数据与处理方
AI 研读主动运行时，宿主 Agent 可读取相关卡片、原文片段、图像或全文。内容由宿主及其模型服务处理。
选文翻译启用时，选中文字和目标语言发送至所选 Bing/Google 服务。部分历史版本默认开启；请检查阅读器设置。已有偏好会保留。
Pages授权创建、关联、同步或导出时，正文、图片和页面信息交给连接的 Pages 服务。
模型及论文下载访问依赖安装源、ModelScope/Hugging Face 或选择的论文网站，涉及请求、下载及常规网络元数据。

本机存储不等于所有功能完全离线。第三方独立处理的数据受其政策、账号和地区规则约束，可能涉及跨境处理；具体由你选用的服务决定。

3. 遥测、网站和支持邮件

Hemistic 不另行收集插件遥测或用户文献，不设置广告、营销追踪或支付收集。本静态网站没有统计脚本、表单或跟踪 Cookie。

网站由 GitHub Pages 托管。GitHub 为安全目的记录访问 IP 等信息；详见 GitHub Pages 数据收集说明及 GitHub 隐私声明。

你发送给 QQ 支持邮箱的邮件可能包含邮箱地址、问题描述和附件，仅用于处理请求。问题关闭后 90 天内删除支持邮件，法律要求保留的除外。请不要发送密码、令牌或未经授权的文献。

4. 保留和删除

本机资料由你管理，通常持续保留至你删除；诊断日志可能包含时间、版本、事件、错误和文件路径，当前没有统一自动清理期限。移出白板不等于删除共享笔记，归档、附件及导出副本也可能继续存在。

需要删除资料时，请分别检查当前资料库、归档、插件设置与日志、导出文件、备份、Pages 及宿主聊天。卸载插件不应被视为删除所有资料。第三方副本请通过对应服务处理。

5. 联系、选择与更新

你可以关闭选文翻译、不运行 AI、不关联 Pages，并按需管理本机文件。有关支持邮件的访问、更正或删除请求，请联系上述邮箱；可能需要确认请求来自邮件本人。依法享有的权利不受本说明限制。

政策变更将在本页更新日期和内容。适用年龄及地区条件同时受宿主平台与所用服务规则约束。
